# Klaket for Claude

AI video ads, social posts and landing pages for your products — made by [Klaket](https://klaket.io) from a conversation with Claude.

| Plugin | What it includes |
|---|---|
| **klaket-studio** | Everything: video ads (4–15 s, scene approval before rendering), social posts and landing pages |
| **klaket** | Social posts and landing pages |

## Install

**Claude (web, desktop, Cowork):** Customize → Plugins → Add → Add marketplace → paste `https://github.com/primeforgedigital/klaket-claude` → install **klaket-studio**. Then connect Klaket from the plugin's Connectors tab.

**Claude Code:**

```
/plugin marketplace add primeforgedigital/klaket-claude
/plugin install klaket-studio@klaket
```

**Just the connector:** Settings → Connectors → Add custom connector → `https://klaket.io/mcp`.

You need a Klaket account with a plan (klaket.io). Creating uses your Klaket credits, at the same price as on the website.

## Privacy

Claude talks to your Klaket account only after you authorize it on klaket.io. See each plugin's README and https://klaket.io/en/legal/privacy.
